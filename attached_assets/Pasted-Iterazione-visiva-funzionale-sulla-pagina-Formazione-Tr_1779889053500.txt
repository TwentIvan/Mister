typescriptfunction rowPositionsForFormation(formation: number[]): number[] {

typescriptfunction migrateLineup(
  oldLineup: SlotState[],
  oldModule: number[],   // es. [1, 4, 3, 3]
  newModule: number[],   // es. [1, 4, 4, 2]
  oldCaptainId: number | null
): { newLineup: SlotState[]; benchAdditions: number[]; lostPlayers: number[]; captainStillValid: boolean } {
  // Mappa ruolo → giocatori attualmente schierati
  // Per ogni ruolo, tieni min(oldCount, newCount) giocatori, riassegnali ai nuovi slot di quel ruolo
  // I giocatori in eccesso vanno spostati alla panchina (se ci sono slot liberi) o ritornano in rosa
  // I nuovi slot non riempiti restano vuoti
  // Caso speciale T: T accetta MID, quindi un MID in eccesso può andare in T se disponibile
  // Capitano: se ancora schierato → resta capitano; se finito in panchina o rosa → captainStillValid = false
}
Regole dettagliate:

GK→GK: keep
DEF→DEF: keep min(old, new), surplus → panchina (se libera) o rosa
MID→MID + T: distribuisci. Per esempio:

Old 4-4-2 (4 MID) → New 4-3-1-2 (3 MID + 1 T): tieni 3 MID nei nuovi slot MID, il 4° va in T (T accetta MID)
Old 3-4-1-2 (4 MID + 1 T) → New 3-5-2 (5 MID): tieni i 4 MID nei 4 primi slot MID, il T (un MID) va nel 5° slot MID


ATT→ATT: keep min(old, new), surplus → panchina o rosa

Surplus → destinazioni in ordine:

Primo posto libero in panchina (mantenendo il vecchio ordine se già stava in panchina)
Altrimenti torna in rosa (non schierato)

Capitano:

Se il capitano resta titolare → resta capitano
Se il capitano va in panchina o rosa → captainId = null, mostra hint nella toolbar "Capitano resettato"

UI feedback: al cambio modulo, mostra un toast informativo brevemente "Modulo cambiato. X giocatori riassegnati, Y rimasti in rosa" — sobrio, no emoji.
