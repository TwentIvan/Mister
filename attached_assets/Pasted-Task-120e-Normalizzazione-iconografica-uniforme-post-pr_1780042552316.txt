Task 120e - Normalizzazione iconografica uniforme (post-process locale)

OBIETTIVO
Tutti gli avatar Toy occupano il cerchio del badge in modo uniforme.
L'INTERA immagine iconografica (testa + capelli + tutto il cutout) deve
avere l'asse maggiore della sua bbox al 95% del canvas. Niente face
detection: l'immagine intera e' l'iconografia da uniformare.

ALGORITMO (puro sharp, locale, nessuna API esterna)
Per ogni avatar finale (BG trasparente, canvas 512x512):
  1. Carica con sharp e raw extract del canale alfa
  2. Trova bbox pixel non trasparenti (alpha > 16):
       minX, minY, maxX, maxY
  3. width  = maxX - minX
     height = maxY - minY
     axisMax = max(width, height)
  4. targetSize = 512 * 0.95   (= 487 pixel)
     scaleFactor = targetSize / axisMax
  5. bboxCenterX = (minX + maxX) / 2
     bboxCenterY = (minY + maxY) / 2
  6. Operazioni sharp:
     a. extract({ left: minX, top: minY, width, height }) - crop tight
        alla bbox
     b. resize larghezza_nuova = width  * scaleFactor,
                altezza_nuova  = height * scaleFactor (mantieni aspect)
     c. extend / composite su canvas 512x512 con padding trasparente,
        centrato (gravity center)
     d. .webp().toFile(output)

RISULTATO ATTESO
- L'asse maggiore della testa = ~487 px (95% di 512) in ogni avatar
- Aspect ratio originale della testa preservato (no deformazioni)
- Centratura: la bbox e' centrata nel canvas
- Per teste larghe: la larghezza tocca quasi i lati del cerchio
- Per teste alte: l'altezza tocca quasi top/bottom del cerchio
- Uniformita' percepita nel badge: tutte le teste arrivano vicino al
  bordo del ring
