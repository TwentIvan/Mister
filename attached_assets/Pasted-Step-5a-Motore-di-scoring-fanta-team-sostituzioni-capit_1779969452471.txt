Task 108 — Scoring engine (funzione pura)
Crea una funzione computeFantaTeamScore in un modulo condiviso (valuta se in @workspace/voto-engine o un nuovo lib/scoring). Firma:
typescripttype ScoringInput = {
  lineup: { module: string; captainPlayerId: number | null; players: LineupPlayer[] };
  playerVoti: Map<number, number | null>;  // playerId → voto_mister round X (null = S.V.)
  playerRoles: Map<number, 'GK'|'DEF'|'MID'|'T'|'ATT'>;
  config: { captainMultiplier: number };   // default 1.5
};

type ScoringResult = {
  effectiveEleven: Array<{ playerId: number; voto: number; wasSubstitute: boolean; replacedPlayerId?: number }>;
  substitutions: Array<{ out: number; in: number }>;
  captainBonus: number;
  totalScore: number;
};
Logica:

Identifica i titolari (isStarter=true, 11 giocatori)
Per ogni titolare, leggi il suo voto da playerVoti:

Se ha voto valido → conta
Se NULL (S.V., non ha giocato ≥15min o squadra non in campo) → sostituzione


Regola sostituzione (fantacalcio classico):

Per ogni titolare S.V., scorri la panchina in ordine di priorità (benchOrder ascendente)
Trova il primo panchinaro dello stesso ruolo (slotPosition, con T che accetta MID) che abbia voto valido E che non sia già entrato per un altro titolare
Quel panchinaro sostituisce il titolare S.V. nel calcolo
Se nessun panchinaro eligibile → il titolare resta S.V. e conta come 0 (o secondo regola: in classico un titolare S.V. senza sostituto vale 0... ma verifica, alcune leghe danno 4 o 5. Per MVP: vale 0)


Calcolo somma:

Somma i voti degli 11 effettivi (titolari validi + sostituti entrati)
Capitano: se il capitano ha voto valido (ha giocato), il suo voto conta ×captainMultiplier (1.5). Se il capitano è S.V. ed è stato sostituito, nessun bonus capitano (il sostituto entra a ×1)
totalScore = somma_voti_effettivi + (voto_capitano × (multiplier - 1)) se capitano valido



Restituisci ScoringResult completo (utile per debug e per mostrare le sostituzioni in UI poi).

Capitano S.V. → nessun bonus, sostituto entra a ×1
Titolare S.V. senza panchinaro eligibile → conta 0
