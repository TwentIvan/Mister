Task 94 — Crop landmark-based
BlazeFace restituisce 6 landmark per ogni volto, nell'ordine: [rightEye, leftEye, nose, mouth, rightEarTragion, leftEarTragion]. Usiamo questi per normalizzare la composizione di ogni avatar a una forma identica.
Nuovo algoritmo di crop: sostituisci preCropFace con la versione landmark-based:
typescriptfunction landmarkBasedCrop(
  detection: BlazeFaceDetection,
  imageWidth: number,
  imageHeight: number
): { left: number; top: number; size: number } {
  // BlazeFace landmark order: rightEye, leftEye, nose, mouth, rightEar, leftEar
  const [rightEye, leftEye, _nose, mouth] = detection.landmarks;
  
  // Eye midpoint (centro orizzontale e verticale di riferimento)
  const eyeCenterX = (leftEye[0] + rightEye[0]) / 2;
  const eyeCenterY = (leftEye[1] + rightEye[1]) / 2;
  
  // Mouth Y come riferimento verticale inferiore
  const mouthY = mouth[1];
  
  // "Face unit" = distanza occhi-bocca (proxy della scala del volto)
  const eyeToMouthDist = mouthY - eyeCenterY;
  
  // Validazione: se la distanza è anomala, fallback al bounding box
  if (eyeToMouthDist < 5 || eyeToMouthDist > imageHeight * 0.6) {
    return fallbackBoundingBoxCrop(detection, imageWidth, imageHeight);
  }
  
  // PARAMETRI CALIBRATI per composizione uniforme:
  // - K = 3.8 → crop size = ~3.8x la distanza occhi-bocca
  // - EYE_OFFSET_FROM_TOP = 0.38 → posiziona occhi al 38% dall'alto
  // Risultato: mouth si trova naturalmente al ~64% dall'alto
  const K = 3.8;
  const EYE_OFFSET_FROM_TOP = 0.38;
  
  const cropSize = eyeToMouthDist * K;
  const cropTop = eyeCenterY - (EYE_OFFSET_FROM_TOP * cropSize);
  const cropLeft = eyeCenterX - (cropSize / 2);
  
  return { left: cropLeft, top: cropTop, size: cropSize };
}

Applicazione del crop con sharp:
Il crop calcolato può sforare i bordi dell'immagine originale (parte del volto + margine può cadere fuori). Usa sharp con questa strategia:

Calcola le coordinate effettive: actualLeft = max(0, cropLeft), actualTop = max(0, cropTop), actualRight = min(imageWidth, cropLeft + cropSize), actualBottom = min(imageHeight, cropTop + cropSize)
Estrai con .extract({ left: actualLeft, top: actualTop, width: actualRight - actualLeft, height: actualBottom - actualTop })
Se ci sono bordi mancanti (cioè actualLeft > cropLeft o simile), usa .extend() per padding bianco { r: 255, g: 255, b: 255 } o trasparente
Resize finale a 512×512 con fit: 'fill' (non cover, perché la geometria è già esatta)
Output PNG → buffer → invia a Replicate
